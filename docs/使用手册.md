## 快速开始

### 第零步（可选）：USB 一键安装

手机用数据线连电脑、开启 USB 调试后，双击 `pc/安装到手机.bat`
即可自动安装并启动 APK。

### 第一步：手机端（装 APK）

把 `apk/VpnShare-v1.0.apk` 传到手机安装即可（需允许「安装未知来源应用」）。

- 包名 `com.vpnshare.app`，最低 Android 7.0
- 免 root、无广告、不联网上报

打开后点「启动共享」，界面会显示三个地址：

```
HTTP 代理 : 192.168.43.1:8080
SOCKS5    : 192.168.43.1:1080
PAC 脚本  : http://192.168.43.1:8080/proxy.pac
```

**记住这个 IP**，下一步要用。

### 第二步：手机开 VPN

先连上你的 VPN，确认 VPN 是**全局模式**。
（如果是分应用模式，需要把 VpnShare 加入 VPN 的应用列表）

### 第三步：电脑端（推荐用图形界面版）

1. 让手机和电脑连**同一个 WiFi / 热点**
2. **双击 `pc-gui/dist/VpnShare.exe`**
3. 在 UAC 弹窗点「是」（改系统代理需要）
4. 点界面上的 **「一键启动共享」**
5. 状态灯变绿、显示代理地址，就成功了

想手动指定（跳过扫描）时，在界面上填 `手机IP` 和 `端口`，再点启动。

6. **用完了点「停止共享」，或直接关窗口** —— 系统代理自动还原。

> 界面还有「仅探测（不修改系统）」「还原系统代理」「复制代理地址」三个辅助按钮。

## 电脑端图形界面版（exe）说明

### 为什么做了 exe 版

原来的 `.bat + PowerShell` 方案有几个实际使用中的问题：

| 问题 | exe 版的处理 |
|---|---|
| 扫描时会把 `169.254.*`（网卡没拿到 IP 的无效地址）也加进候选 | 已过滤 |
| 只排除 `255.*` 前缀，漏掉 `192.168.x.255` 这类**广播地址** | 已按末位 `.255` 精确排除 |
| 依赖 `Get-NetNeighbor` / `Get-NetIPAddress` 等 PS 模块，精简系统上拿不到数据 | 改用 `arp -a` + 注册表，兼容性更好 |
| 中文路径 / UTF-8 编码在部分终端下显示乱码 | GUI 内部统一 UTF-8，不经过终端 |
| 只看黑窗口文字，不知道到底成没成 | 状态灯 + 日志面板，一眼看清 |

### 界面功能

| 区域 | 说明 |
|---|---|
| 状态灯 | 灰=未启用，黄=正在处理，绿=共享中 |
| 一键启动共享 / 停止共享 | 主按钮，随状态自动变成对应操作 |
| 仅探测（不修改系统） | 只扫描手机代理在不在，不动系统设置 |
| 还原系统代理 | 手动还原（上次异常退出等情况） |
| 复制代理地址 | 把 `http://手机IP:端口` 复制到剪贴板，方便填到别的软件 |
| 手动指定 | 直接填 IP:端口，跳过扫描（最快） |
| 日志面板 | 每一步的结果都记下来 |
| 关闭时自动还原 | 默认勾选，关窗即还原 |

### 重新打包（改了代码之后）

```bash
cd pc-gui
.venv\Scripts\python.exe build.py
# 产物在 dist\VpnShare.exe
```

### 排查启动问题

如果双击 exe 没反应，去看这个日志（一定可写，不受 exe 位置限制）：

```
%LOCALAPPDATA%\VpnShare\boot.log     启动过程打点
%LOCALAPPDATA%\VpnShare\error.log    启动失败的异常堆栈
```

### 如果电脑连不上手机代理

先确认两者**在同一网段**：

```bash
# 手机 IP（注意接口名可能是 wlan2 而非 wlan0）
adb shell ip -4 addr

# 电脑 IP
ipconfig
```

不在同一网段时，有两个办法：

1. **让电脑连手机的热点**（推荐，最快）
2. **用 USB 直连模式**：双击 `pc/USB直连模式.bat`，
   它用 `adb forward` 把手机端口映射到电脑本地，
   之后电脑用 `127.0.0.1:18080` 即可

## 电脑端脚本用法

### 图形化（双击）

| 文件 | 作用 |
|---|---|
| `一键启动-共享VPN.bat` | 自动发现 + 设置代理，关窗自动还原 |
| `扫描手机代理.bat` | 只扫描，看手机代理开没开、在哪个端口 |
| `还原代理.bat` | 手动还原（比如上次异常退出没还原） |

### 命令行（更灵活）

```powershell
# 手动指定（最快，跳过扫描）
.\Start-VpnShare.ps1 -ProxyHost 192.168.43.1 -ProxyPort 8080

# 只扫描不修改
.\Start-VpnShare.ps1 -ScanOnly

# 还原
.\Start-VpnShare.ps1 -Restore

# 只用 HTTP 代理，不设 PAC
.\Start-VpnShare.ps1 -ProxyHost 192.168.43.1 -ProxyPort 8080 -NoPac

# 设置代理后立即退出，不常驻（代理保持生效）
.\Start-VpnShare.ps1 -ProxyHost 192.168.43.1 -ProxyPort 8080 -KeepOnExit

# 扫描自定义端口
.\Start-VpnShare.ps1 -PortsToScan 8080,8888,3128
```

## 手机端脚本用法（Termux 备选方案）

```bash
bash vpnshare.sh              # 启动（默认 HTTP 8080 / SOCKS5 1080）
bash vpnshare.sh status       # 查看状态和当前 IP
bash vpnshare.sh stop         # 停止
bash vpnshare.sh restart      # 重启
```

自定义端口和鉴权：

```bash
HTTP_PORT=9999 SOCKS_PORT=1090 bash vpnshare.sh
PROXY_USER=me PROXY_PASS=1234 bash vpnshare.sh    # 开启鉴权
ENABLE_SOCKS=0 bash vpnshare.sh                   # 只开 HTTP
```

## 手动配置（不想用脚本时）

### Windows 系统代理

设置 → 网络和 Internet → 代理 → 手动设置代理：

- 地址：`192.168.43.1`（换成你手机的实际 IP）
- 端口：`8080`
- 或者选「使用设置脚本」，填 `http://192.168.43.1:8080/proxy.pac`

### Firefox

Firefox 默认不读系统代理，需要手动设：
设置 → 网络设置 → 自动代理配置 URL：
`http://192.168.43.1:8080/proxy.pac`

### 其他软件

大多数支持 HTTP 代理的软件都能填 `192.168.43.1:8080`。
需要 SOCKS5 的（比如某些下载工具）填 `192.168.43.1:1080`。

## 排错

### 扫描不到代理

```bash
# 先确认能 ping 通手机
ping 192.168.43.1
```

- ping 不通 → 手机热点开了**客户端隔离**，换热点或改用 USB 网络共享
- ping 通但扫不到 → 手动指定端口试试 `-ProxyHost 手机IP -ProxyPort 8080`
- 手机上确认 VpnShare 是否显示「运行中」

### 代理连上了但上不了网

1. 手机 VPN 是不是全局模式？
2. VPN 里把 VpnShare 加进应用白名单
3. 电脑上关掉 Clash / v2rayN 等占用系统代理的软件

### 电脑网速很慢

无线链路带宽有限，尤其手机做热点时。
可以试试把电脑的 DNS 改成 `223.5.5.5` 减少解析延迟。

### 关机/崩溃后代理没还原

双击 `还原代理.bat` 即可。
如果连备份也没了，脚本会退化为「清空代理恢复直连」。

## 安全性说明

- APK 默认**不鉴权**，同一局域网内任何人都能用你的代理。
  在公共 WiFi 下**务必在 App 里填写「访问认证」用户名密码**。
- 所有数据都在本地局域网流转，APK 本身不请求任何外部服务器。
- 唯一的出网口是手机自己的 VPN，和你手机平时上网走的是同一条路。
